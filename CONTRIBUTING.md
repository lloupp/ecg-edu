# Contributing

Obrigado por contribuir com o ECG Edu!

## Como contribuir
- Faça um fork do repositório
- Crie uma branch para sua feature ou correção
- Envie um Pull Request com uma descrição clara

## Padrão de Commits
- Use Conventional Commits (ex: feat:, fix:, docs:)

## Código de Conduta
- Seja respeitoso e colaborativo

## Testes
- Garanta que todos os testes estejam passando antes do PR
